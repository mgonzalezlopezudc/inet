# Packet-capture manifest history

This directory contains historical AX packet-capture manifests. New sessions
created by the shared analyzer are published under
`examples/ieee80211/analysis/generated/ax/pcapmanifests/`, with the latest
mirror at
`examples/ieee80211/analysis/generated/ax/pcap_statistics_manifest.json`.

Do not edit or replace a session manifest. Generate a new session ID when the
captures, scalar metadata, source state, binary, or analysis tools change.
