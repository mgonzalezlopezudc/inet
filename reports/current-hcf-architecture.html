Current HCF implementation

Hcf is the runtime coordinator: it binds composed NED dependencies to stateful exchange ownership, stateless frame services, and amendment-specific feature adapters.

Coordination hub

Hcf owns the active exchange, callbacks, timers, runtime bindings, and amendment delegation while the extracted services keep common routing logic small.

State ownership is explicit

  • HcfExchangeEngine owns exchange progression and response timing.
  • HcfMacSapTracker accounts service-data-unit identity and bytes.
  • Aggregation, retry, ACK, and BlockAck owners remain authoritative.

Composition boundary

The NED default is CommonHcfFeatureSet; VHT and HE feature sets add amendment-specific services and adapters selected during initialization.
