# 6LoWPAN completion evidence

> **Kind:** report · **Status:** current · **Seal:** none · **Owns:** — · **Stands on:** [coverage](coverage.md), [publication verification](publication/manifest.json)

Original P8–P15 contracts are implemented in the publication units mapped by [coverage](coverage.md). Stateful contexts and extension NHC precede their discovery/context-distribution consumers. Generic ND representation and validity queries precede native ownership policy. Registrar/authority behavior precedes automatic updated hosts. Native completion precedes pacing, virtual forwarding and selective recovery. The MTU correction stays with virtual forwarding before recovery.

The final acceptance record identifies the tested source tree and libraries for enabled debug, targeted release, feature-off, UDP-disabled and exact required-feature configurations. Per-commit focused checks and per-PR combined checks remain separate records. Reordered C19/C20/C22/C23 source surfaces and every executable fixture version were independently checked against the approved slices.

The two new generic protocol cases exercise final-address ICMPv6 checksum/error budgeting and byte-form IPv6 fragment continuation. Their compatible parent observations are retained separately: the first stops at its Echo assertion before PTB; the second crashes during expired decoded-header access in the observed run. These do not establish every allocator or configuration.

Debug assertions establish the finite tested fields and ownership invariants. Targeted release checks completion and unconditional observations with assertions disabled. Older host setup with side effects inside assertions is excluded from all-suite release parity. Expected initialization/runtime diagnostics and the known external elided-EUI failure are not reported as ordinary success.

Original stage JSON files, source hashes and captures retain their original cohorts. [Input snapshots](publication/input-snapshots/README.md) preserve the original prose without replacing new results. The corrected direct-example checks use the local launcher and explicit library/NED roots; the original wrong-checkout direct-example attempt is retained and superseded only for that scope.
