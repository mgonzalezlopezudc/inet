Stateful 6LoWPAN IPHC contexts

The optional 6LoWPAN adaptation layer supports RFC 6282 stateful IPHC with up to 16 per-interface compression contexts, independent source/destination context selectors, stateful multicast, receive-only contexts and absolute validity limits. Configure LowpanLayer.compressionContexts; an empty configuration retains stateless behavior. Prefix replacement invalidates partial reassembly, while already decoded first-fragment addresses remain stable when their context expires.
