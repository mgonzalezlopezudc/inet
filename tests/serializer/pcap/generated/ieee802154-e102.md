# IEEE 802.15.4 E1-02 IE wire-vector captures

These synthetic version-2 DATA frames use independent fixed FCF and IE octets
for all eight IEEE Std 802.15.4-2024 Table 7-6 Header/Payload/Data combinations,
an optional Payload Termination, a level-1 auxiliary header with a four-byte
opaque MIC, and a reserved-level-4 opaque remainder. They are structural
vectors: no security authentication or over-the-air interoperability is claimed.

Generate both link types from the repository root with Python's standard
library and the independent M1 polynomial-division FCS oracle:

```sh
python3 tests/serializer/tools/generate_ieee802154_enhanced_vectors.py
```

Link type 195 includes FCS; link type 230 omits it. The generator prints the
SHA-256 of each complete capture. The serializer test requires typed frame
dissection and exact byte replay, with no top-level raw fallback.
