Run 4 is a source-traced regression for the down-owner timer dispatch defect: ingress STOP closes the forwarding record and history maintenance can remain scheduled at its original deadline. Dispatch through `LowpanLayer::handleMessageWhenDown` must recognize or safely cancel this real helper timer rather than cast it to Packet. There is no fabricated timer or private state access. The old A train ends before 12 s; only its first frame crosses B. Keeping the actual layer stopped until 121 s makes the 120 s history expiry reachable before restart. This source trace predicts a failure on the defective production path; it is not an executed parent comparison.
